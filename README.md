## 三条最重要的结论

1. **新店的矛盾不是"没曝光"，是"给你曝光你接不住"** —— 系统先给小流量测试，点击率/转化率不达标就收回。所有动作都指向"接住曝光"。
2. **标准品已经没利润了** —— 1688 与淘宝价差基本消失，拼多多把价格锚点拉到更低。要么做非标（场景化/组合/换人群），要么别做。
3. **两条不可逆红线** —— 连续 5 周无在售商品店铺被彻底释放；连续 30 天不登录且无成交自动打烊。

## 可信度标注

每份文档都给结论标了来源等级：

- **【官方】** 淘宝/阿里妈妈/1688 官方页面原文
- **【二手】** 行业媒体、社区、服务商文章（多家一致时采信，但不是平台承诺）
- **【未核实】** 流传广但找不到可靠出处，当"可以试，别当真理"
- **【我的估算】** 推算，附算式，参数可自行修改

> 淘宝的搜索算法没有公开说明书，网上大量"权重公式"是二手经验。各文档末尾都有"未核实清单"，把流传广但无官方出处的说法单列。

## 重要声明

**这是概率游戏，不是投资。** 500 元买不到"月入过万"，买到的是一次低成本试错。本文档不承诺任何收益。

商品表里的采购价、售价、退货率**全部是估算**，不是平台真实数据 —— 你必须自己去 1688 和淘宝核一遍，不要拿文档数字当决策依据。
